# Installation

Install `dotkernel/dot-router` by executing the following Composer command:

```shell
composer require dotkernel/dot-router
```

## Requirements

- **PHP**: 8.3, 8.4, 8.5 or 8.6
- **laminas/laminas-stratigility**: ^3.0 || ^4.0
- **mezzio/mezzio-fastroute**: ^3.15

Upgrading from version 1? Read the [upgrade guide](upgrading.md).
